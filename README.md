# Sports-Databases-CSC370
A database of NHL Seasons, the games played that season, the teams that played,
the players that played and about those players.

The goal of this sprint was to create a Database for our chosen topic by:
- Creating an Entity Relationship Diagram. (found under docs/ERD.png)
- Implementing that relational design using. SQL DDL(found under sql/schema) 
- Normalize it into BCNF.(found under docs/bcnf)

Moving into the next sprint the main goals we'll be moving towards will be:
- Analyzing our ERD more in depth to make sure it meets all of the eight "design criteria"
- Compare what our database would look like in 3rd normal form and 4th where it's appropriate
- Re-evalute our weak entities and if they need to be modified or implemented differently
- Insert and delete data based on query predicates(SQL DML)
